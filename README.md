# PK142864 Emulator

PK142864 is a browser-based multi-system emulator front-end.

## Supported systems

- NES
- Game Boy
- Game Boy Advance
- SNES
- Nintendo 64
- PlayStation 1

## Features

- Drag-and-drop ROM loading
- File picker
- Fullscreen mode
- Simple settings (audio toggle, FPS target)
- ROM library browser
- Mobile-friendly touch controls (basic)

## Usage

1. Open `index.html` via GitHub Pages or a local server.
2. Select a system from the dropdown.
3. Load a ROM via:
   - File picker, or
   - Drag-and-drop onto the drop zone, or
   - Clicking a ROM from the ROM library list.
4. Use fullscreen for better experience.

## Folder structure

See `emu/cores` for core stubs and `roms/` for sample ROMs.
